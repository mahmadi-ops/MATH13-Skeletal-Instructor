Definition 4.7.1. Local Maximum and Local Minimum.

Let the domain of the function \(f(x,y)\) contain the point \((a,b)\text{.}\) Then
🔗
  • \(f(a,b)\) is a local minimum if \(f(a,b) \le f(x,y)\) for all the points \((x,y)\) in an open disk centered at \((a,b)\text{.}\)
    🔗
    🔗
  • \(f(a,b)\) is a local maximum if \(f(a,b) \ge f(x,y)\) for all the points \((x,y)\) in an open disk centered at \((a,b)\text{.}\)
